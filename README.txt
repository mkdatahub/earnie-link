P.V.T. & T. Plas Registration Page

ไฟล์ในชุดนี้
- register.html
- register.css
- register.js

วิธีใช้
1. นำทั้ง 3 ไฟล์ไปวางในโฟลเดอร์เดียวกับ index.html เดิม
2. ตรวจสอบว่ามีไฟล์โลโก้อยู่ที่:
   /images/Logo-บริษัท(ใช้งานจริง).png
3. เปิด register.html เพื่อทดสอบ
4. ปุ่ม "เข้าสู่ Link Hub" จะกลับไปที่ ./index.html

สำคัญ
เวอร์ชันนี้เป็นหน้า UI และตรวจสอบข้อมูลเท่านั้น
ข้อมูลยังไม่ได้บันทึกเข้า Supabase

ข้อมูลที่เตรียมไว้ใน JavaScript:
- customer_name
- company_name
- phone_number
- consent
- registered_at
