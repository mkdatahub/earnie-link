# P.V.T. & T. PLAS E-Catalog

ชุดหน้าเว็บ E-Catalog พร้อมใช้งานบน Cloudflare Pages

## หน้าเว็บ
- `catalog.html` หน้ารวมสินค้าและค้นหา
- `product.html?id=shade-net` หน้ารายละเอียดสินค้า
- `catalog/PVTT_E_Catalog_050826.pdf` แคตตาล็อก PDF

## แก้ข้อมูลสินค้า
แก้ไฟล์ `data/products.js` แล้ว push ขึ้น GitHub ตามปกติ

## หมายเหตุรูปภาพ
รูปสินค้าใช้รูปที่มีอยู่ในไฟล์ PowerPoint ที่ผู้ใช้ส่งมา สินค้าบางประเภทใช้ภาพตัวแทนร่วมกัน เนื่องจากต้นฉบับไม่ได้มีภาพแยกครบทุกหมวด
